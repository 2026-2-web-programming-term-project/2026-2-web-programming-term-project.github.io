## 공통 기준

- UI 설계서는 18개 화면·팝업·반응형 항목을 정의합니다. M01·M02는 U01·U04와 기능·검증을 공유합니다.
- 예약 1시간 단위·최대 연속 8시간·10분 전 알림 등은 제안값이며 운영 전 확정합니다.
- 예약과 실제 GPU 상태, 웹 처리량과 GPU 장비 용량을 구분합니다.
- GPU 작업 자동 실행·강제 중지와 대기자 자동 배정은 현재 설계 범위에 포함하지 않습니다.
- 성능·복구 목표는 측정 전에 합격 기준을 정하고 검증 결과와 함께 기록합니다.
- 현재 상태 표기는 계획 기준입니다. 날짜가 지났다는 이유로 완료 상태로 변경하지 않습니다.
